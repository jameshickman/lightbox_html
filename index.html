Lightbox Grid

A dependency-free carousel / masonry / rows widget with a same-origin iframe lightbox. See test.html for the automated + manual test harness.

1. Carousel (default) · toggle enabled · 4s autoplay

data-mode="carousel" data-timer="4000" — autoplay pauses on hover/focus and stops on manual navigation. Click any slide to open it in the lightbox.

    • Aurora — northern light fields
    • Coral — warm reef mornings
    • Meadow — green rolling calm
    • Amber — golden hour glow
    • Violet — deep dusk hues
    • Lagoon — still tidal blue

2. Rows (default) · optional titles · all three modes selectable

data-mode="rows" — justified "expanding rows" (photo-platform style): images keep their aspect ratio and each row scales to fill the full width. Each item may include an optional title between the image and the link; titles of different lengths (and one item with none) still line up because every tile in a row grows to a consistent height. Use the toggle to switch between Carousel, Masonry (uniform columns), and Rows.

3. Masonry · toggle disabled

data-mode="masonry" data-toggle="off" — the mode-switch UI is suppressed and the widget is locked to masonry.

    • Coral

4. Rows · toggle disabled

data-mode="rows" data-toggle="off" — locks the widget to the justified rows grid with no mode-switch UI. Theme follows whichever stylesheet the page loads (use the Light/Dark toggle up top).

    • Aurora — northern light fields
    • Amber — golden hour glow
    • Meadow — green rolling calm
    • Violet — deep dusk hues
    • Lagoon — still tidal blue
    • Coral — warm reef mornings

5. <div> markup · rows · optional titles

The same widget, sourced from nested <div>s rather than nested lists. Div containers use data-rel="lightbox-grid" (rel is not a valid attribute on a <div>); everything else — modes, titles, the lightbox — behaves identically.
